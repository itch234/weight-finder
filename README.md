# ウェイトファインダー

画面の中の「重さ」がどちらに偏っているかを測って、カメラを向け直す方向を出すWebアプリです。
ビルドも依存パッケージも不要で、`index.html` をブラウザで開くだけで動きます。

**公開URL:** https://itch234.github.io/weight-finder/

## できること
- **カメラを起動** — ライブ映像をリアルタイム判定(カメラの利用には https 配信が必要)
- **撮影** — 構図が整ったらその場で保存。切り抜き枠(比率)の中身をカメラの解像度のままJPEGにします。スマホでは共有シート(写真に保存など)、パソコンではダウンロード。一時停止中の画面も撮影できます
- **カメラ切替** — 前面 ⇄ 背面を切り替え。前面カメラは鏡像で表示し、判定・矢印・保存もその向きに揃えます
- **写真で判定** — 手元の画像ファイルを読み込んで判定。パソコンでは画像のドラッグ＆ドロップや貼り付け(Ctrl+V)でも読み込めます
- **複数写真の比較** — 写真をまとめて選ぶと、画面下に一覧が並び、いまの判定モード・比率での点数を各写真に表示します。いちばん高い写真に黄色の印。タップ(または ← → キー)で切り替え
- **この枠で保存** — 写真で判定中は、選んだ比率で切り抜いたJPEGを保存できます
- **デモで試す** — 写真やカメラの許可なしで、サンプル画像の判定を体験
- **終了する** — カメラの使用を停止し、最初の画面に戻る
- **重心モード** — 画面全体の重さの中心が中央付近に来るよう、カメラを振る方向を矢印で表示
- **三分割モード** — 主役を三分割構図の交点に乗せる方向を表示
- **重さマップ** — 重いと判定された領域を可視化
- **比率** — フル / 3:2 / 4:3 / 5:4 / 1:1 / 16:9 のトリミング枠を切り替え
- **振動の合図** — ライブ判定で構図が整った瞬間に短く振動します(対応端末のみ)。画面を見ずに構えているときの目印
- **設定の記憶** — 判定モード・比率・カメラの向きは、次に開いたときも引き継がれます
- **ホーム画面に追加** — スマホのブラウザから「ホーム画面に追加」すると、全画面のアプリとして起動でき、オフラインでも開けます

写真では重さの偏りと主役の位置を表示し、ライブ映像ではカメラを向け直す方向を表示します。
点数は目標の構図への近さの目安で、写真の良し悪しを評価するものではありません。
写真・映像はブラウザ内で処理され、サーバーへ送信されません(表示フォントはGoogle Fontsから読み込みます)。

重心・三分割の選択は、Tabで移動した後に矢印キーまたはHome / Endでも切り替えられます。
パソコンでは、ボタン以外にフォーカスがある状態でスペースキーを押すと撮影・保存できます。
カメラの起動中でも写真・デモを選択でき、最後に選んだ入力が優先されます。
読み込めない画像やカメラの起動失敗時には、表示中の写真を残してエラーを案内します。

## 重さの推定方法
各ピクセルをCIE Lab色空間に変換したうえで、以下を合成して「重さ」としています。

- 大域の目立ち(画面平均色との差)
- 局所の目立ち(周囲との差)
- 細部の密度(輝度のSobel勾配)
- 鮮やかさ・暖色ほど重くなる補正
- 画面の上にあるものほど重く感じる補正

解析は長辺160pxに縮小したフレームに対して行い、ライブ時は指数移動平均で結果を平滑化しています。
複数写真の比較では、各写真を長辺320pxに縮小して保持し、モードや比率を変えるたびに採点し直します(最大60枚)。

## ファイル構成
- `index.html` — アプリ本体(解析コアとUIをすべて含む)。これ1つだけでも動きます
- `manifest.webmanifest` / `sw.js` / `icons/` — ホーム画面への追加とオフライン起動のためのファイル。`sw.js` はページ本体をネットワーク優先で取得するので、更新はそのまま反映されます
- `tests/` — 解析コアの回帰テストとブラウザ操作テスト

## ローカルで動かす
カメラを使うには `https` か `localhost` である必要があります。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## GitHub Pages の設定
Settings → Pages → Source に `Deploy from a branch`、Branch に `main` / `(root)` を選んで Save。
`.nojekyll` はJekyll処理をスキップするために置いています。

## テスト

Node.js 22以降で、依存パッケージを追加せずに解析の回帰テストを実行できます。

```sh
npm test
```

ブラウザの操作テストは、Playwright(`playwright` または `playwright-core`)が利用可能な開発環境で `npm run test:browser` を実行します。
既存のChromium系ブラウザ(Edge / Chrome)を使う場合は、環境変数 `BROWSER_PATH` に実行ファイルの絶対パスを指定してください。
デモ、画像の読み込み、キーボード操作、画面サイズ、撮影・保存、設定の記憶、複数写真の比較、ドラッグ＆ドロップ、カメラの拒否・タイムアウト・入力切替・前後切替・停止を検証します。
カメラはテスト用の映像で代用しているため、実機のカメラやOSの許可ダイアログ、共有シートは別途確認が必要です。
スクリーンショットは `test-results/` に出力します。
